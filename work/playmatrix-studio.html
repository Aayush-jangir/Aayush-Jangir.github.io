PlaymatriX Studio

The studio's own website, rebuilt end to end. The old site had every image broken, no security headers and no way for the team to change anything without a developer.

Visit playmatrixstudio.com
RoleDesign, development and deployment
StackNext.js, Payload CMS, Postgres, Cloudflare R2
HostingRailway behind Cloudflare
StatusLive since September 2026

The problem

All 34 images on the old site returned errors, because uploads had been saved to the server's own disk and were wiped on every redeploy. The site sent zero security headers, its media catalogue could be listed by anyone, and only the previous developer held the accounts.

What I built

  • A new public site and an admin panel, from one codebase, so the team edits their own work
  • Media on Cloudflare R2, so images can never be lost on a redeploy again
  • Security headers, locked private fields and SVG uploads blocked
  • Enquiry emails delivered straight to the studio inbox
  • Nightly automatic database backups
  • Automated checks for colour contrast in both themes, 200% text zoom on every page, and phone layouts

Results

94 to 99Google PageSpeed score on phone
100PageSpeed score on desktop
100Lighthouse accessibility and SEO

The team can now publish new work themselves, and every enquiry arrives by email.

What I learned

Speed is a hundred small decisions, from trimming fonts to caching images properly, and the only way to keep it is to measure on every change. The same tools Google uses are the ones I run before anything goes live.
